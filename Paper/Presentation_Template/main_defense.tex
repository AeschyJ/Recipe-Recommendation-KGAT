          \item 使用者面臨資訊過載，難以快速找到符合偏好的食譜。
          \item \textbf{傳統協同過濾 (CF)}：僅依賴歷史互動，面臨資料稀疏與冷啟動限制。

        \vspace{0.3cm}
      \end{exampleblock}
      \vspace{0.2cm}
      \small \textbf{轉場點}：知識圖譜 (KG) 提供了豐富語意關係，但其真實效益與注意力解釋的可信度不能被直接假定。
    \end{column}

\begin{frame}{KGAT 的潛力，也帶出三個尚未回答的問題}
  \begin{itemize}
    \item \textbf{協同知識圖譜 (CKG)}：將使用者--食譜互動與食譜屬性（食材、標籤）統一建構為 CKG。
    \item \textbf{KGAT 特點}：透過關係感知注意力機制 (Relation-aware Attention) 與多跳傳播，擷取高階語意關聯。
  \end{itemize}
  
  \vspace{0.3cm}
  \begin{block}{既有研究的三大缺口 (Research Gaps)}
    \begin{enumerate}
      \item \textbf{食譜領域驗證}：KGAT 缺乏在大規模真實食譜場景 (Food.com) 的深度實證。
      \item \textbf{逐層機制剖析}：缺乏對不同傳播深度 ($1L/2L/3L$) 與輔助資訊增益的深入消融分析。
      \item \textbf{解釋真實性質疑}：注意力權重路徑是否忠實 (Fidelity) 反映模型的真正決策？
    \end{enumerate}
  \end{block}
\end{frame}

      \end{block}
    \end{column}
  \end{columns}

  \centering
  \textbf{遞進邏輯}：效能驗證 (RQ1) $\longrightarrow$ 訓練機制解構 (RQ2) $\longrightarrow$ 解釋真實性檢驗 (RQ3)

% ==================================================
% Slide 7: 本研究的貢獻
% ==================================================
\begin{frame}{本研究的貢獻是效能、機制與解釋三層驗證}
  \begin{itemize}
    \item \textbf{貢獻 1：食譜領域大規模實證}
      \begin{itemize}
        \item 在 Food.com 實作 CKG，進行 KGAT-1L/2L/3L 與基線模型 (BPR-MF, NFM, LightGCN) 的嚴謹對比。
      \end{itemize}
    \item \textbf{貢獻 2：揭露淺層 KG 的「資訊污染」機制}
      \begin{itemize}
        \item 發現單跳傳播下引入 KG 輔助資訊反而可能稀釋協同過濾訊號，釐清深度整合與超級節點修剪的必要性。
      \end{itemize}
    \item \textbf{貢獻 3：建立注意力路徑 Fidelity 評估管線}
      \begin{itemize}
        \item 提出邊擾動測試檢驗路徑必要性 ($F^+$) 與充分性 ($F^-$)，跨深度與路徑類型評估解釋的真實忠實度。
      \end{itemize}
  \end{itemize}
\end{frame}

\begin{frame}{KGAT 四階段視覺化架構與訊息傳播公式}
  \begin{columns}[T]
    \begin{column}{0.38\textwidth}
      \begin{block}{高階視覺化流程}
        \centering
        \vspace{0.1cm}
        \begin{tikzpicture}[node distance=0.4cm, auto, >=stealth, scale=0.8, every node/.style={transform shape}]
          \node[draw=NTUBlue, fill=NTUBlueLight, rectangle, rounded corners, font=\small\bfseries, minimum width=3.2cm, align=center] (step1) {1. CKG 建構\\異質圖與自迴圈};
          \node[draw=NTUBlue, fill=NTUBlueLight, rectangle, rounded corners, font=\small\bfseries, minimum width=3.2cm, align=center, below=of step1] (step2) {2. 關係感知注意力\\$\pi(h,r,t)$ 選擇權重};
          \node[draw=NTUBlue, fill=NTUBlueLight, rectangle, rounded corners, font=\small\bfseries, minimum width=3.2cm, align=center, below=of step2] (step3) {3. 雙重互動聚合\\Bi-Interaction Agg.};
          \node[draw=NTUBlue, fill=NTUBlueLight, rectangle, rounded corners, font=\small\bfseries, minimum width=3.2cm, align=center, below=of step3] (step4) {4. 跳躍拼接 (JK)\\$e_u^* = e_u^{(0)} \parallel \dots \parallel e_u^{(L)}$};
          
          \draw[->, thick, NTUBlue] (step1) -- (step2);
          \draw[->, thick, NTUBlue] (step2) -- (step3);
          \draw[->, thick, NTUBlue] (step3) -- (step4);
        \end{tikzpicture}
      \end{block}
    \end{column}
    
    \begin{column}{0.59\textwidth}
      \begin{block}{1. 關係感知注意力 (Relation-aware Attention)}
        \[
        \pi(h, r, t) = \text{Softmax}\left( W_r t \cdot \tanh(W_r h + e_r) \right)
        \]
      \end{block}
      
      \begin{block}{2. 雙重互動聚合 (Bi-Interaction Aggregation)}
        \[
        e_h^{(l)} = \text{LeakyReLU}\left( W_1^{(l)} (e_h^{(l-1)} + e_{N_h}^{(l)}) + W_2^{(l)} (e_h^{(l-1)} \odot e_{N_h}^{(l)}) \right)
        \]
      \end{block}
      
      \begin{block}{3. 跨層拼接與偏好預測 (JK Pooling)}
        \[
        e_u^* = e_u^{(0)} \,||\, e_u^{(1)} \,||\, \dots \,||\, e_u^{(L)}, \quad \hat{y}(u,i) = {e_u^*}^T e_i^*
        \]
      \end{block}
    \end{column}
  \end{columns}
\end{frame}

\section{可解釋性忠實度評估}

% ==================================================
% Slide 15: RQ3 可解釋性 Fidelity 評估架構
% ==================================================
\begin{frame}{路徑要成為解釋，必須通過必要性與充分性雙重檢驗}
  自關係感知注意力萃取 Top-3 高權重路徑，進行**邊擾動測試 (Edge Perturbation)**：
  
  \begin{columns}[T]
    \begin{column}{0.48\textwidth}
      \begin{block}{1. 必要性 $F^+$ (Fidelity-plus)}
        從 CKG 中\textbf{移除}解釋路徑，觀察預測機率下降程度：
        \[
        F^+ = p(u,i) - p(u,i \setminus \mathcal{P})
        \]
        \textbf{$F^+ > 0$ 代表該路徑為決策的必要條件}。
      \end{block}
    \end{column}
    
    \begin{column}{0.48\textwidth}
      \begin{block}{2. 充分性 $F^-$ (Fidelity-minus)}
        遮蔽其餘邊，\textbf{僅保留}解釋路徑，觀察預測維持程度：
        \[
        F^- = p(u,i) - p(u,i|_{\mathcal{P}})
        \]
        \textbf{$F^- \approx 0$ 代表該路徑本身即具充分資訊}。
      \end{block}
    \end{column}
  \end{columns}
\end{frame}

\section{結論與未來展望}

% Slide 19: 結論
% ==================================================
\begin{frame}{結論：深度提升效能與路徑覆蓋，但 KG 與注意力需審慎驗證}
  \begin{enumerate}
    \item \textbf{效能層面 (RQ1)}：KGAT-3L 在 Food.com 食譜推薦上取得優於 LightGCN 的表現 (\textbf{HR@20 +31.6\%, NDCG@20 +38.4\%})。
    \item \textbf{機制層面 (RQ2)}：揭露淺層 KG 整合可能造成資訊污染 ($L=1$ w/o KG 0.7076 > Full 0.6761)；深層模型收斂極快且更需 Early Stopping。
    \item \textbf{解釋層面 (RQ3)}：深層模型顯著提升解釋路徑覆蓋率 (55.6\%)；但 Fidelity 證實直連與協同路徑高忠實，KG 語意路徑充分性偏低。
  \end{enumerate}
  
  \vspace{0.3cm}
  \centering
  \textbf{核心主張}：可解釋推薦系統應同時進行\textbf{「推薦準確度」}與\textbf{「解釋忠實度 (Fidelity)」}的雙重驗證。
\end{frame}

\begin{frame}{Backup C: KGAT 損失函數與細節}
  BPR Loss 結合 L2 正則化：
  \[
  \mathcal{L}_{\text{KGAT}} = \sum_{(u, i, j) \in \mathcal{O}} -\ln \sigma \left( \hat{y}(u,i) - \hat{y}(u,j) \right) + \lambda \|\Theta\|_2^2
  \]
  其中正樣本對為 $(u,i)$，負採樣樣本為 $(u,j)$，$\lambda = 10^{-5}$。
\end{frame}

\begin{frame}{Backup E: Fidelity 方法限制與分佈偏移 (Distribution Shift)}
  \begin{block}{分佈偏移 (Distribution Shift)}

  \end{block}
\end{frame}
