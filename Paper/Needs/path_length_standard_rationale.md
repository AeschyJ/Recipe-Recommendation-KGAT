# 知識圖注意力網路可解釋性路徑長度設定依據與學術標準說明

## 一、 原始程式碼之實作設定依據

在專案之注意力解釋器模組（`src/model/explainer_attention.py` 第 87 至 91 行）中，路徑搜尋之實作設定如下：

```python
# KGAT 預設 2 層，所以我們找長度 <= 3 的路徑 (nodes: u -> e1 -> e2 -> i)
paths = list(
    nx.all_simple_paths(
        G, source=u_id, target=i_id_global, cutoff=n_hops + 1
    )
)
```

1. **參數計算與邊數定義**：
   - 解釋器預設傳入之跳數為 `n_hops = 2`。
   - 圖論套件 NetworkX 之 `cutoff` 參數嚴格定義為「路徑最大邊數」。
   - 代碼中設置 `cutoff = n_hops + 1 = 3`，代表搜尋**邊數 $\le 3$（即節點數 $\le 4$）**之簡單路徑。
2. **評估實驗的一致性**：
   - 於全體 500 位使用者之忠實度評估腳本（`src/evaluate_fidelity.py` 第 114 行）中，預設參數為 `n_hops = min(len(layers), 2)`。
   - 因此，論文第四章實驗所呈現之忠實度指標（$F^+$ 與 $F^-$）及注意力路徑分佈，皆在此一最大邊數為 3 的規範下產出。

## 二、 長度 $\le 3$ 條邊之學術標準與理論必然性

在知識圖譜推薦系統（如 KGAT、RippleNet、KPRN、CAFE 等文獻）之可解釋性研究中，將路徑長度定為 3 條邊具有嚴謹之理論依據與圖拓撲限制：

### 1. 協同知識圖之三部圖結構限制
本研究建構之協同知識圖（$\mathcal{G}_{\text{CKG}}$）本質為三部圖架構：
- 使用者節點集 $\mathcal{U}$ 僅與食譜節點集 $\mathcal{V}$ 存在互動關係邊。
- 實體節點集 $\mathcal{E}$（食材與標籤）僅與食譜節點集 $\mathcal{V}$ 存在語義關係邊。
- 食譜與食譜之間無直連邊。

因此，對於查詢使用者 $u \in \mathcal{U}$ 與推薦目標食譜 $v \in \mathcal{V}$：
- **長度 1 條邊**：$u \to v$（僅代表歷史已互動之直連邊，無法作為未互動候選項目之推理中間路徑）。
- **長度 2 條邊**：使用者的鄰域 $\mathcal{N}(u)$ 全為食譜，目標食譜的鄰域 $\mathcal{N}(v)$ 全為使用者或實體，兩者集合永遠互斥（$\mathcal{N}(u) \cap \mathcal{N}(v) = \emptyset$），數學上不存在長度為 2 條邊的有效路徑。
- **長度 3 條邊（4 個節點）**：為跨越三部圖鴻溝、串聯使用者偏好與目標推薦之最短且唯一結構形式：
  $$u \xrightarrow{\alpha_1} r_1 \xrightarrow{\alpha_2} m \xrightarrow{\alpha_3} v$$
  其中 $r_1 \in \mathcal{N}(u)$ 為歷史互動食譜，而中繼節點 $m \in \mathcal{N}(r_1) \cap \mathcal{N}(v)$ 為兩道食譜之共鄰實體：
  1. **協同過濾元路徑**：$m$ 為另一位共同互動使用者，形式為 `使用者 -> 歷史食譜 -> 共同互動者 -> 推薦食譜`。
  2. **知識圖語義元路徑**：$m$ 為共享之食材或標籤，形式為 `使用者 -> 歷史食譜 -> 共享屬性 -> 推薦食譜`。

### 2. 圖神經網路感受野對齊
$L$ 層之圖注意力神經網路（KGAT），各節點之特徵表示聚合來自 $L$ 跳範圍內之鄰域結構訊息。在模型傳播深度設定為 $L=2$ 或 $L=3$ 時，長度 3 條邊之路徑完整涵蓋於模型之主要訊息聚合半徑內，為因果效應最強烈之核心路徑。

### 3. 避免語義漂移與維護人類認知極限
認知心理學與可解釋性人工智慧文獻證實：
- 長度為 3 條邊之三元推論（例如：*因曾喜愛食譜 A，A 包含食材 B，故推薦含有食材 B 之食譜 C*）符合人類直覺推理鏈結。
- 若將長度擴展至 4 條、5 條或更長之邊數，會引發嚴重之語義漂移，因果關聯被過度稀釋。
- 同時，注意力權重連乘值（各邊 Softmax 權重均小於 1）隨跳數呈指數級衰減至 $10^{-6}$ 以下，對最終推薦機率與忠實度評估之貢獻趨近於零，失去解釋價值。

- 目標精確窮舉滿足 $m \in \mathcal{N}(r_1) \cap \mathcal{N}(v)$ 之所有中繼節點。
