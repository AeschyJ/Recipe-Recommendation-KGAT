# 碩士學位口試互動展示系統

本目錄包含碩士學位論文口試現場使用之圖神經網路推薦推論與忠實度檢測展示系統。系統採用雙軌架構，支援遠端桌機即時推論與口試筆電完全離線展示，兼顧全圖即時運算能力與口試現場網路波動之備援可靠性。

---

## 系統核心架構與功能

展示系統涵蓋模型推論、解釋路徑萃取、忠實度遮蔽探針計算與前端圖拓樸視覺化：

1. **多模型即時推論**：支援知識圖注意力網路不同傳播深度（一跳、二跳、三跳）、消融版本（無知識圖、無注意力）以及基準模型（LightGCN、NFM、BPR-MF）之推薦信心預測。
2. **高速向量化尋路**：基於壓縮稀疏列矩陣之局部閉環尋路演算法，於數毫秒內完成使用者至食譜之最高注意力權重路徑檢索。
3. **圖遮蔽干預檢測**：精確計算必要性忠實度與充分性忠實度，透過聯集子圖邊緣遮蔽驗證解釋路徑對推薦決策之因果貢獻。
4. **拓樸互動狀態機**：動態呈現原始預測、遮蔽解釋子圖以及僅保留解釋子圖三種拓樸干預樣式，並配合脈衝光流與淡出動畫對齊論文理論。

## 雙軌運行指引

### 模式一：連線推論模式

適用於具備網路連線且後端推論伺服器正常運行的情境，可針對資料集中任意使用者進行全庫即時推論。

1. **啟動後端伺服器**：
   在具備運算資源之主機（如桌上型電腦）雙擊執行 `run_server.bat`，或在終端機執行：
   ```powershell
   uv run demo/server.py --port 8501 --host 0.0.0.0
   ```
2. **連接展示介面**：
   開啟瀏覽器訪問 `http://localhost:8501`。
3. **跨網路展示**：
   若透過筆記型電腦連線至遠端桌機，可使用 Cloudflare Tunnel 或虛擬區域網路將主機端口映射至外網，並在前端介面點選「伺服器」按鈕設定遠端位址。

### 模式二：完全離線展示模式

適用於口試現場網路不穩或無外部伺服器連線之離線備援情境。

1. **啟動展示介面**：
   直接雙擊執行 `run_offline_laptop.bat`，或以任意現代瀏覽器直接開啟 `demo/web/index.html`。
2. **無跨來源資源共用限制**：
   系統透過 `demo_cases_data.js` 以全域物件注入離線資料，即使在檔案協定下直接開啟亦不會觸發瀏覽器安全性阻擋。
3. **展示內容**：
   內建五組完整論文典型案例（深度傳播成功案例、高必要性案例、高充分性案例、淺層隨機噪音案例、孤立節點案例）與五百位評估使用者之推薦結果與忠實度指標。

## 連接埠與路徑規範

- **連接埠限制**：為避免與本機其他開發服務發生衝突，後端伺服器預設監聽 8501 端口，嚴禁佔用 8000 端口。
- **路徑解耦**：所有程式碼與腳本皆使用動態探測錨定專案路徑，不包含任何本機使用者目錄或絕對路徑，確保不同機器間之可移植性。
- **日誌記錄**：後端推論詳細歷程自動記錄於專案根目錄之 `output/logs/demo_server.log`。

## 快取資料更新

若重新訓練模型或更新評估結果，可重新執行萃取腳本以更新離線快取資料：

```powershell
uv run demo/export_demo_cases.py
```

該腳本將自動讀取評估產出，重新計算典型案例指標與五百位使用者快取，並同步產出 `demo_cases.json` 與 `demo_cases_data.js`。
